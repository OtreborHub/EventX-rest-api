EventX

REST API — gestione eventi, location, ticket e recensioni

Endpoints disponibili

  • POST /api/v1/utenti — Registrazione
  • POST /api/v1/utenti/login — Login
  • GET /api/v1/eventi — Lista eventi
  • GET /api/v1/location — Lista location
  • POST /api/v1/ticket — Acquisto ticket
  • POST /api/v1/recensioni — Nuova recensione
